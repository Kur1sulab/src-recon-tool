## 0. 一句话定位

给「持续盯实时遥测」的信息收集值守场景做的一套深色控制室界面：冷蓝石板五级底、青鹤唯一强调色、圆形 LED 状态灯、等宽数据列、斑马纹数据行——信息密度优先，装饰为零。

## 1. 定调与谱系

### 1.1 为什么是深色控制室

1. **内容本质是实时遥测**：五页的主要内容是任务状态、模块进度、日志尾的 800ms 轮询刷新，阅读动作是"扫状态"，不是"读文档"。
2. **终端原生内容在暗底上才协调**：任务 ID、目标、URL、耗时、时间戳全部是等宽字体，这套语汇放浅色图纸上会割裂。
3. **与同族桌面安全面板同族不同貌**：共用"多级暗底 + 单一品牌强调 + 状态色只做语义不做装饰 + 等宽数据纪律"的家族基因，但具体取值（冷蓝相石板底 + 青鹤强调 + 圆形 LED）自成体系，不引用任何同类扫描器产品的具体样式值。
4. **长时间值守的用眼成本**：一轮信息收集数分钟起步，多任务并盯时暗底低亮度更可持续。

### 1.2 谱系声明

信息架构（aside 侧栏 + 分组导航、页面骨架公式、卡头内嵌筛选）参考同族桌面壳谱系（CyberStrikeAI `web/next/index.html:39-59`、zcode-app-go `frontend/index.html:86` 注释即声明"IA 参考、样式独立"）；样式与本方案令牌完全独立。行业形态对标：Burp 顶层工具 tab + 表格筛选（portswigger.net 桌面文档，本会话调研引用）、Nessus 严重度过滤按钮组 + 单条详情钻取（docs.tenable.com，同上）、Zenmap"同一份结果多视图"（原始日志即真相源，与结构化表并存）。

### 1.3 红线排除（违反即返工）

- **零对话组件**：聊天流、气泡、发送按钮、计划卡、意图解析一律不进任何页面（反面案例：CyberStrikeAI 作业台聊天流、vesper chatPane，仅记录为反例）。交互载体只有：表单、表格、按钮、下拉、菜单、确认框、toast。
- **零 AI**：无 AI 功能、无联网模型调用。
- **零遥测**：无任何数据上报；网络访问仅限本地 127.0.0.1 服务。
- **零外链**：无网络字体、无 CDN、无 `url()` 资源引用（CSP `default-src 'self'`，`index.html:6`）。
- **产品命名**：用户可见文案一律「信息收集工具」「新建任务」；不出现「侦察工具」作为产品名（现状已合规：`index.html:7,22,34`，前端三文件 grep 零「侦察」命中）。

### 1.4 明确不引入的调研项（记录理由）

| 调研采纳项 | 不引入理由 |
|---|---|
| 分组折叠导航（CyberStrikeAI NAV_GROUPS） | 五页规模用不上；页数 >5 再启用 |

## 2. 色板（全部 hex）

颜色单一来源 = 令牌文件（生产 `frontend/css/tokens.css`；本提案草稿 `A-tokens.css`）。组件层只写 `var()`，禁止裸色值。生产现状 grep 审计（调研轮执行）：`app.css` 零裸色值、`index.html` 零内联 style、`js/` 零 `.style.color` 动态赋值——本方案延续该纪律。

### 2.1 中性底盘

| 层 | 令牌 | hex | 用途 |
|---|---|---|---|
| 画布 | `--s0` | `#0c1116` | 应用最底、日志凹井 |
| 骨架 | `--s1` | `#101820` | 侧栏、顶栏、输入井 |
| 面板 | `--s2` | `#151f28` | 卡片标准底 |
| 交互井 | `--s3` | `#1b2732` | 行悬停、下拉悬停 |
| 强井 | `--s4` | `#223040` | 按钮悬停、选中井 |
| 斑马纹 | `--zebra` | `#121b23` | 数据表偶数行（比面板沉半档） |

线条三阶（全部 1px，不做粗线）：`--ln-1 #1e2b36`（行分隔）、`--ln-2 #273745`（面板边/控件边）、`--ln-3 #354857`（悬停边/强调边）。

文字三阶：`--tx-1 #dee6ec`（主文）、`--tx-2 #9aabb9`（次文：标签/表头/提示）、`--tx-3 #7a90a4`（弱注：脚注/快捷键/分页信息）。

### 2.2 品牌青鹤（唯一强调色）

| 令牌 | hex | 用途 |
|---|---|---|
| `--acc` | `#3cb8a8` | 焦点环、激活轨、刻度记号、主按钮底、运行态 |
| `--acc-hi` | `#74d6c7` | 青底悬停、链接、运行态文字 |
| `--acc-lo` | `#1d4a43` | 描边档（行悬停 2px 内轨） |
| `--acc-ink` | `#04201b` | 主按钮上的文字 |
| `--acc-bg` | `#102e2b` | 导航选中井 |

**硬规则：青鹤绝不参与状态语义**（绿=完成、橙=警示、红=故障已被占用）。品牌色与状态色分离是安全工具界面的关键纪律。

### 2.3 状态色族（每色三档：主档 + `-lo` 描边 + `-bg` 淡底）

| 语义 | 主档 | 描边 `-lo` | 淡底 `-bg` |
|---|---|---|---|
| 完成/在线（ok） | `#63bd80` | `#2a5c3c` | `#15271d` |
| 警示/停止（warn） | `#d9a353` | `#6b5426` | `#2a2216` |
| 故障/离线（err） | `#e07b6c` | `#6e3a33` | `#2c1d1a` |
| 待命/连接中（idle） | `#5b6f82` | （用 `--ln-3`） | `#131c24` |
| **新增 A1** 信息型（info，预配） | `#5aa9e6` | `#2e4d66` | `#11222e` |

新增状态色必须三档齐备并过 §2.7 门槛；不做 rgba 现场混色（保证零色值泄漏到组件层）。

### 2.4 严重度→色族映射（新增 A2 语义别名，不新增色值）

安全工具惯例（Trivy/Grype/npm audit 共识，调研轮 WebSearch 确认）：CRITICAL/HIGH→红、MEDIUM→黄/橙、LOW→绿/青、UNKNOWN/INFO→灰/蓝。本体系映射：

| 严重度 | 色族 | 区分手段 |
|---|---|---|
| crit | `--err` 族 | **700 字重 + 实心圆点**（不新增第二红色相） |
| high | `--err` 族 | 400 字重 + 圆点 |
| medium | `--warn` 族 | — |
| low | `--idle` 族 | — |
| info | `--info` 族（A1 预配） | — |

消费前提：结果出现分级维度时才启用；`--sev-*` 只是 `var()` 别名，见 `A-tokens.css`。

### 2.5 辅助令牌

点阵地板 `--dot-grid`（次文色 5% 透明的 1px 圆点，24px 网格，主区地板，窄窗关闭）；阴影两档 `--sh-1`（卡片贴面）/`--sh-2`（仅浮层）；动效时长 `--dur-breathe: 1.6s`、`--dur-toast: 0.18s`。

### 2.6 硬边界（本轮实测，写入令牌注释）

1. **`--tx-3` 禁上 `--s4`**：实测 `#7a90a4` 对 `#223040` = **4.06:1 < 4.5**。落在强井上的文字至少用 `--tx-2`（实测 5.69:1）。
2. **`--idle` 圆点禁放 `--s3` 交互井底**：实测 `#5b6f82` 对 `#1b2732` = **2.92:1 < 3.0**（非文字门槛）。待命灰点只能对 `--s2`（3.21:1）或 `--idle-bg`（3.31:1）。
3. **`--idle` 不作文字色**：实测对 `--s2` 仅 3.21:1 < 4.5。待命灰只做圆点/描边，文字一律换 `--tx-2`/`--tx-3`。
4. `-lo` 描边档对 `--s2` 为发丝级（err-lo 1.84 / info-lo 1.88 / ok-lo 2.14 / warn-lo 2.32），只做描边，禁作文字。

## 3. 字体与字号阶梯

### 3.1 字体栈（系统栈，零外链）

- UI 字 `--font-ui`：`"Segoe UI", "Microsoft YaHei UI", "PingFang SC", "Noto Sans CJK SC", sans-serif`
- 等宽字 `--font-mono`：`ui-monospace, "Cascadia Mono", Consolas, "Courier New", monospace`

### 3.2 字号严格五档（档外禁用）

| 档 | 值 | 固定映射 |
|---|---|---|
| `--fs-11` | 11px | 表头 / kbd / 铭牌 / 统计标签 |
| `--fs-12` | 12px | 徽标 / 脚注 / 日志 / 分页信息 |
| `--fs-13` | 13px | 正文与表格数据（基准档） |
| `--fs-14` | 14px | 输入框 |
| `--fs-15` | 15px | 页题 / 品牌名 / 统计大数字（配 600 字重） |

数字要更醒目靠**字重与状态色**，不靠放大字号；不新增第六档。

### 3.3 行高三档

`--lh-tight: 1.4`（标题/徽标）、`--lh-body: 1.55`（正文）、`--lh-log: 1.6`（日志/等宽数据）。

### 3.4 等宽数据纪律

ID、目标、URL、耗时、大小、时间戳、白名单条目、日志一律等宽 + `font-variant-numeric: tabular-nums`（生产已内建于 `.mono`/`td.num`/`.chip`/`.logview`/`.stat-num`/`.pager-info`/`.wl-list`）。800ms 轮询刷新时列位不跳，靠的就是等宽 + tabular-nums。

### 3.5 OpenType 特征结论（本轮 otfeat.py 实测，命令见验证记录 2）

```
Cascadia Mono: aalt calt case ccmp frac zero ss02(比较连字) sups/subs …（无 tnum）
Consolas:      calt case ccmp dlig onum ss01..ss08(等号/比较/箭头/省略号等连字) …（无 zero、无 tnum）
```

四条硬规则：

1. **只用高级属性 `font-variant-numeric`，禁低级 `font-feature-settings`**——低级属性一次声明整体替换继承列表（font-features SKILL Gotchas），嵌套元素会意外丢特征。
2. **不启用 `zero`**——Consolas 无此特征，跨机字形不一致；两字体默认零形均已与字母 O 区分。
3. **不启用任何连字集**（ss01–ss08 / dlig）——日志与路径必须字符原样，`->` 不能渲染成箭头（Consolas 的 ss03 正是箭头连字，实测确认存在，必须保持默认关闭）。
4. `tnum` 对纯等宽字体是无操作（两字体实测均无此特征），保留它只作护栏；真正的纪律是**数字必须落在等宽元素内**。

## 5. 表格密度

三标杆共识（Burp/Nessus/Zenmap，调研轮确认）：数据密排、等宽列固定、精简列集、详情走行点击钻取而非大弹窗、筛选常驻列表正上方。

1. **行高 ≈34px**：`td` 上下 7px padding + 13px 基准字号（生产 `app.css:294-298` 实测值）。这是唯一密度档，**不做密度开关**。
2. **表头**：11px + 500 字重 + 0.06em 字距 + `--tx-2` 色（`app.css:283-292`）。表头用 `--tx-2`（7.07:1），不用弱注档。
3. **数据行三件套**（每张数据表必须齐备）：
   - 斑马纹：偶数行 `--zebra`，表头行不参与（`app.css:301`）；
   - 悬停：整行抬到 `--s3` + 首格 2px 暗青内轨（`inset 2px 0 0 var(--acc-lo)`，box-shadow 即时切换不补间，`app.css:304-307`）；
   - 焦点：全局 2px 品牌青 `:focus-visible` 环（`app.css:34-37`，按钮上内缩防裁切）。
4. **等宽列固定集**：任务 ID / 目标 / URL / 路径 / 耗时 / 大小 / 时间戳列一律 `td.mono` 或 `td.num`（数字列右对齐）。
5. **折行**：长目标/长路径 `overflow-wrap: anywhere`（`app.css:336`），不出现横向滚动。
6. **分页统一**：所有数据表一律 `PAGE = 50` 客户端分页（`App.paginate` + `App.renderPager`，`app.js:198-222`），上一页/下一页 + mono 页码指示，单页时不渲染分页器；翻页页码在轮询间保持（详情页现状正确样板，`detail.js:17-18,85-87`）。
7. **列集纪律**：固定精简列集（5–6 列），不提供自定义列；新增列须先证明必要。
8. **表格语义**：`th` 加 `scope="col"`、表加 `caption`（可视觉隐藏）、行内操作按钮 `aria-label` 携带行上下文（如「查看任务 a1b2c3d4 xycovo.com」）。

## 6. 壳层与信息架构

### 6.1 骨架

`.app` = 两列 grid（`224px + minmax(0,1fr)`，`app.css:66-70`）+ 主区纵向 flex（顶栏 → 离线横幅 → 滚动主面板，`app.css:72-85`）；100vh 单视口，仅主面板滚动，无页面级滚动条叠加。主面板铺 24px 点阵地板（`app.css:79-85`），面板浮于其上；窄窗关闭纹理。单视图最大 1080px（`app.css:87`）。

### 6.2 顶栏

左 = 页题 `h1.view-title`（15px/600，切页更新）；右 = Esc 提示（仅存在运行中任务时显示，`app.js:356-361`）。侧栏脚承担全局状态：LED 圆点 +「本地服务在线/后端离线/正在连接」文字 +「仅限授权目标扫描」常驻注记（`index.html:50-56`）。

### 6.3 侧栏

品牌铭牌（SVG 标 +「信息收集工具」+ src-recon-tool）+ 五项导航（图标 + 文字 + `kbd` 快捷键提示）+ 底部状态区。激活项：`--acc-bg` 井底 + `aria-current="page"`（`app.js:285-290`）。五页规模不引入分组折叠。

### 6.4 离线横幅与状态灯

`role=alert` 全站横幅（`index.html:68-70`）：说明文字 +「立即重试」按钮（本提案新增，现状只有文字）；离线期间表单禁用，恢复后轮询自动刷新。LED 三态：在线绿 / 离线红 / 连接中橙，`data-state` 驱动（`app.js:366-373`）。

### 6.5 键盘协议

- **Ctrl+1..5** 直切五页（`e.key` 与 `e.code` 双路识别 + preventDefault，`app.js:306-317`）；侧栏 kbd 常驻提示。
- **Esc 三级优先**：应用内模态关闭 > 停止运行任务 > 交还输入控件。输入框/下拉/多行/可编辑区/**IME 组合中**一律放行不误触（`app.js:321-329`）。
- **Esc 停止改两段式**（本提案 P0 修正）：首次按仅 toast「再按一次 Esc 确认停止任务 xxx」，2 秒内再按才真停——现状一键即停（`app.js:328`），长跑任务误停代价高。
- **切页焦点管理**（本提案 P0 修正）：路由切换后焦点移到页题（`#viewTitle` 补 `tabindex="-1"` 并 `focus()`）——现状切页焦点掉到 body（`app.js:275-299`），键盘用户须从头 Tab，读屏器也无播报。
- hidden 视图移出 Tab 序（原生 `hidden`，`app.js:281-284`）。

### 6.6 轮询节奏（自适应，本提案修正）

现状固定 800ms（`tasks.js:193`、`detail.js:258-265`）。改为：存在运行中任务 800ms；全空闲 2000–2500ms；停止/删除等动作后立即补拉一轮。终态任务自动停轮询（详情页现状已做，`detail.js:190-191`）。

### 6.7 窄窗降级

≤760px：侧栏收成 64px 图标轨（隐藏文字/kbd/铭牌），关闭点阵纹理。高 DPI 实机复核列入 §14 风险。

### 6.8 页面级状态

每页持有页面级状态对象（筛选值、当前页码），切页往返不丢（借鉴 vesper 页级状态模式，调研轮 `app.js:1325`）；现状详情页分页页码已保持（`detail.js:85-86`），列表页引入筛选/分页后同样保持。

## 8. 组件规范

1. **chip 状态徽标**：胶囊描边态（`--r-full`）+ 圆点 LED + 文字；按 `data-s` 契约着色——`created` 待命灰、`running` 亮青字 + LED 呼吸（唯一带动画的状态）、`done` 绿、`fail` 红、`stopped` 橙；未知值无配色规则时自然回退中性描边（安全默认）。设置页旗标用 `chip-lv-ok/-bad`。
2. **按钮**：主按钮青底墨字（悬停亮青）/ 次按钮石板井（悬停强井）/ 停止按钮红字描边（悬停红淡底）。按钮实高 ≈31px（6px 14px 内边距），≥28px 点击目标。按压反馈 `translateY(1px)`，悬停即时换色不补间。
3. **LED 圆点**：8px 圆（统计卡 10px），只配三处背景色来源：状态族主档/`--acc`/`--idle`；遵守 §2.6 硬边界②。
4. **toast**：状态回执条 `role=status`，`--s3` 井底 + `--sh-2`，进场 0.18s（opacity + translateY(6px)）；ok/err 两变体走对应 `-bg` 淡底。toast 只报结果，不承载对话。
5. **离线横幅**：`role=alert` + warn 淡底 +「立即重试」按钮；离线期间提交类表单禁用。
6. **应用内确认框（新增，替代 window.confirm）**：不可逆操作（删除任务）用应用内确认小面板——标题含任务短 id 与目标、后果说明（删记录/进度/日志，`out/` 保留）、取消/确认双键、焦点困住、Esc 关闭、确认进行中禁点（参照 zcode 模态纪律，调研轮 `app.js:803-871`）。理由：`window.confirm` 在 WebView2 壳内的表现未实测（§14），应用内面板最稳且样式可控。
7. **分页器**：mono 页码信息（`--tx-3` 12px）+ 上一页/下一页按钮；`pager:empty` 隐藏。
8. **kv-grid**：两列键值块（键 11px `--tx-2`，值 13px `--tx-1`，mono 值走 mono）。
9. **白名单盒**：`--s1` 输入井底 + 圆点条目列表（`.wl-list` mono）+ 口径脚注。

## 10. 动效与 reduced-motion

1. **通道只有两个**：`opacity` 与 `transform`。颜色/边框/填充类状态一律即时切换，禁 transition 补间。
2. **持续动画全站 ≤1 种**：LED 呼吸 `breathe 1.6s` 仅 opacity 1→0.3（`app.css:453-456` 族），运行态专属（任务 chip、统计卡 live 点）。
3. **进场 ≤180ms、位移 ≤6px**：toast/抽屉进场 `0.18s ease-out`。
4. **按压位移**：按钮 `translateY(1px)`。
5. **reduced-motion 全局兜底**：`@media (prefers-reduced-motion: reduce)` 下全部动画/过渡压至 0.01ms + `animation-iteration-count:1`（`app.css:699-705`）。该块必须保持在 app.css 末尾不被移除——新增动画自动被覆盖。LED 呼吸在 reduce 下退化为常亮圆点，状态语义仍由颜色区分，不丢信息。
6. **进度不做模拟动画**：进度表/状态只随真实轮询数据变化，无假加载条、无占位假数。

## 14. 风险与不适用场景

1. **低分屏点阵莫尔纹**：24px 点阵在低 DPI 屏可能出现干涉纹，实施轮需实机检查；不行就降级为纯 `--s0` 地板。
2. **窄窗/高 DPI 未实机复核**：≤760px 图标轨与 150% 缩放下的密度、发丝线渲染待实机验收。
3. **`window.confirm` 在 WebView2 壳内的表现未实测**（本轮未启动应用），故 §8.6 直接改应用内确认框规避。
4. **`--info`/`--sev-*` 为预配**：当前五页无消费页，落位后 lint 会有 orphan 告警（与生产 `-lo` 档同类，属已知保留）；若最终不做分级维度，删别名即可，零成本。
5. **不适用场景**：浅色打印/报告排版、文档批注型界面、需要品牌情感化的展示页——本体系为值守监控专用，不做浅色主题（避免双主题维护与对比度回归翻倍）。
6. **自动化验收缺口**：本提案阶段未启动应用做浏览器实机截图验收；实施轮按 webapp-testing（真实开页面）+ desktop-visual-acceptance 流程补齐，并重跑 §2.7 对比度脚本作回归。

# 人工目验清单 —— 打磨轮（2026-10-06）

> 本轮打磨共落地 3 high + 9 medium + 15 low，全部经 `go build + go vet + go test -count=1` 全绿验证（4 包 ok）。
> **自动化验证的边界**：以下条目涉及「像素级对齐 / 观感取舍 / 高缩放下溢出」，代码与单测只能保证逻辑正确，最终效果请按本清单人工过一遍（起 exe 目验即可，无需任何配置）。
> 环境提示：125%/150% 系统缩放下重点看溢出类条目；窗口可拖矮（<760dp 高）验证滚动类条目。

## 一、结果页

1. **任务满一页时分页条与任务详情可达**（H1 修复）
   - 操作：发起一次扫描（或造 ≥18 条任务记录），到「结果」页看任务列表满一屏时，列表下方「‹ 上一页 / 第 x/y 页」分页条与「任务详情 + 过程记录」是否都在窗口内可见（列表本身最多占 300dp 高、超出滚动）。
2. **导出失败的回执是红色**（H2 修复）
   - 操作：选中一个没有产物目录的任务点「导出证据包」，回执行应为红色「导出失败：…」而不是绿色。
3. **停止钮出现/消失不再挤动导出钮**（L 修复）
   - 操作：任务运行中 vs 结束后，右上角「导出证据包」按钮横向位置应纹丝不动（停止钮恒占一个固定槽位）。
4. **停止失败有红字回执**（M 修复，正常环境难以触发可跳过）
   - 期待：停止失败时（如任务已被清理）结果页标题行下出现红色横条；任务一进终态横条自动消失。

## 二、暴露面（第六页）

5. **「检查进行中…」按钮真的点不动**（H3 修复）
   - 操作：点「一键跑全部检查」后按钮变灰，鼠标悬停不再出现按压/悬停反馈，连点不会堆叠出第二个基线任务（结果页任务列表只多一条）。
6. **基线任务失败/被停止后有终态横条**（M 修复）
   - 操作 a：把 engine-go/recon-go.exe 临时改名（或删掉）再点「一键跑全部检查」→ 输入卡下应出现红色横条「基线检查失败——去结果页看该任务的过程记录」，且旧的「基线检查已开始：xxx」不再常驻；改回文件名后换个目标输入，横条消失。
   - 操作 b：任务运行中按 Esc 停止 → 应出现橙色横条「基线检查已停止——…」。
7. **输入非法域名有即时提示**（L 修复）
   - 操作：目标框输入 `http://xycovo.com` 或 `xycovo.com:443`，输入井下方应立即出现灰色小字「目标格式：应为域名（不含协议和端口）」，不用点按钮。
8. **「已跳过」与「有结论」的 LED 颜色**（L 修复，观感取舍）
   - 期待：某检查因预算耗尽被跳过时，卡片 LED 是橙色（与卡顶色条同族），不再是红点橙条并存；某检查结论为 fail 级时，LED 跟结论一样是红色（不再是绿点+红条双信号）。

## 三、设置页

9. **整页可滚动，「关于」卡不再被裁**（M 修复，[需人工目验] 原始条目）
   - 操作：窗口拖矮（或 150% 缩放）进「设置」页，滚轮应能滚到底看到「关于」卡完整三行。
10. **Go 引擎卡载入态**（M 修复）
    - 操作：冷启动立刻进设置页，Go 引擎卡应先显灰色「检测中…」1~2 秒，再变为「已探测到：…」绿字或「未找到（需先构建…）」橙字——不再直接闪「未找到」。
11. **「自检」不再冻窗**（M 修复）
    - 操作：点 Python 卡「自检」→ 按钮旁立即显「自检中…」且窗口不冻结（期间可拖动窗口/切页），几秒后回执按结果红/橙/绿着色；Go 卡同款。探测期间按钮再点无效果（真禁用）。
12. **保存回执按成败着色**（M 修复）
    - 操作 a：「保存并生效」填一个路径 → 绿字「已保存并生效…」。
    - 操作 b：起一个扫描任务运行中再点保存 → 红字「有 N 个任务正在运行…」（不再是中性黑）。

## 四、工具页

13. **「数据落在哪」两列对齐**（M 修复）
    - 期待：「扫描产物目录」「任务库/日志目录」左列标签定宽对齐，右列路径从同一竖线起（不再是空格补位的歪对齐），也无「out\：」悬空反斜杠。
14. **mock「探测」有后台反馈**（M 修复）
    - 操作：点「探测」→ 按钮变禁用、右侧显「探测中…」，约 1 秒内回结果（绿/橙）；期间再点无效。
15. **模块清单行距与分区间距**（L 修复）
    - 期待：十个模块行之间有 4dp 行距不再贴死；mock 靶站卡、依赖卡、数据落点卡三段间距一致（都是 16dp）。

## 五、新建任务页

16. **区块间距统一**（L 修复）
    - 期待：「扫描目标」「选择模块」「可选参数」三个标签到各自控件都是同一档 4dp 间距；表单卡上下内衬与其他页卡片一致（不再上下多一圈）。
17. **成功/错误横条会过期**（L 修复）
    - 操作：发起一次任务看到「任务已开始：xxx」→ 切到别的页再回来横条已清；或改一下目标输入，横条即消失。

## 六、仪表盘

18. **统计卡十字缝对称**（L 修复）
    - 操作：把窗口拖到宽度容不下四卡（自动折 2+2）→ 横缝与纵缝都是 12dp，十字缝对称。
19. **空态提示更醒目**（L 修复）
    - 期待：无任务时空态卡的提示文字是次文灰（Tx2），比「生成于…」脚注深一档，但仍弱于正文。
20. **三条左缘对齐**（L 修复，[需人工目验] 原始条目）
    - 期待：侧栏导航文字（含 3dp 选中轨共 24dp）、顶栏品牌名（24dp）、顶栏右侧铭牌（与主区内容同列 248dp）三条左缘各自对齐成一线，无锯齿感。

## 七、全局/字体（仅特殊环境需要看）

### 本轮已知不动的两处（有意的取舍，勿报缺陷）
- **模块 tab 胶囊保持 80dp**（未统一到 84dp）：11 枚 × 80dp = 880dp ≤ 主区 908dp，保证默认「全部可见」；统一加宽会触发横向滚动，取舍保留原值（DESIGN-native.md §3 有案）。
- **折叠钮/分页钮统一 84dp**，与 tab 胶囊（80dp）不同族——分页与折叠是同族小钮，胶囊是筛选器，两类各自一致。
